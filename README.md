# مسیر اکتور

وب‌اپلیکیشن فارسی آموزش بازیگری بر اساس فایل فیگمای ارائه‌شده. راست‌چین، واکنش‌گرا و بدون وابستگی به کتابخانه یا فرایند build.

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا با Node.js اجرا کنید:

```sh
node server.mjs
```

نشانی پیش‌نمایش: `http://127.0.0.1:4173`

## قابلیت‌ها

- خانه، داشبورد، کتابخانه، جزئیات دوره و اتاق درس
- جستجو، دسته‌بندی، فیلتر سطح و مرتب‌سازی دوره‌ها
- ثبت تکمیل درس، یادداشت خودکار و نمودار تمرین هفتگی
- آزمون خودارزیابی پنج‌سؤالی و پیشنهاد سطح
- چهار تمرین روزانه با زمان‌سنج قابل توقف و ثبت انجام تمرین
- چالش هفتگی، پیش‌نمایش ویدیو و یادداشت اجرا
- خودارزیابی چهارمعیاره و دفتر بازخوردها
- پروفایل و دریافت/بازیابی نسخهٔ پشتیبان JSON
- ذخیرهٔ داده‌ها در localStorage و پخش ویدیوهای محلی با Object URL

داده‌ها در همان مرورگر و همان مبدأ وب باقی می‌مانند. ویدیوها آپلود یا ذخیره نمی‌شوند و پس از بارگذاری مجدد باید دوباره انتخاب شوند. نسخهٔ پشتیبان شامل ویدیو نیست. حذف داده‌های مرورگر باعث حذف اطلاعات محلی می‌شود.

## انتشار روی GitHub Pages

۱. یک مخزن در GitHub ایجاد کنید و فایل‌های پروژه، از جمله پوشهٔ `assets` و فایل `.nojekyll` را داخل آن قرار دهید. پوشهٔ `artifacts` و فایل ZIP تحویل را بارگذاری نکنید.

۲. در تنظیمات مخزن به **Settings → Pages** بروید.

۳. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کنید؛ شاخهٔ اصلی و مسیر **/(root)** را برگزینید و ذخیره کنید.

۴. پس از انتشار، آدرس وب‌سایت در همان صفحه نمایش داده می‌شود.

مسیرها hash-based هستند (`#/courses`)، همهٔ دارایی‌ها نسبی‌اند و برنامه در زیرمسیر یک مخزن هم اجرا می‌شود. نیازی به npm install، کلید API، سرور Node در هاست یا پرداخت نیست. `server.mjs` فقط برای پیش‌نمایش محلی است.

## محدودهٔ این نسخه

این یک نمونهٔ کاربردی از رابط و گردش کار آموزش است؛ حساب آنلاین چندکاربره، احراز هویت واقعی، پرداخت، مدیریت مدرس، آپلود ابری و تحلیل هوش مصنوعی ندارد. نام مدرس‌ها و درس‌نامه‌ها محتوای نمونه‌اند. فایل فیگما ویدیوهای آموزشی واقعی در اختیار برنامه قرار نمی‌دهد؛ برای پخش ویدیو، فایل محلی انتخاب کنید. امتیاز بازخورد را خود هنرجو ثبت می‌کند و نتیجهٔ تعیین سطح نیز خودارزیابی است.

برای تبدیل به SaaS تجاری باید سرویس احراز هویت، پایگاه داده، ذخیره‌سازی ویدیو، نقش‌های دسترسی، محتوای تأییدشدهٔ آموزشی و در صورت نیاز پرداخت در مرحلهٔ بعد اضافه شوند. هیچ راز یا کلید خصوصی نباید در فایل‌های عمومی GitHub Pages قرار گیرد.
